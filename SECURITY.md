# Security

## Reporting a vulnerability

Please report it privately: on GitHub, **Security > Report a vulnerability** on this repository. Don't open a public issue for it.

Say what you found, how to reproduce it, and which version and platform. You'll get an answer within a few days. YARC is maintained by volunteers and has no bounty.

Only the latest release is supported; YARC updates itself, so a fix ships as the next release.

## How changes are checked

Every pull request goes through a security gate before it can merge, and every release is reviewed and approved by a maintainer before it is published: [docs/security-review.md](docs/security-review.md).
